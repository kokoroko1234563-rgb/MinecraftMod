# Axiomatic

A single-player Minecraft tech mod (NeoForge 26.1.2) where you do real mathematics. You start
from Peano's axioms, every definition becomes a machine, and every theorem you prove makes the
factory cheaper. The long-term goal is computing and proving ever larger primes.

- Coal, copper and redstone pay for energy; mathematics decides how wisely it is spent.
- Any property can be checked case by case (energy per case) or proven once (free forever).
- Conjectures are a gamble: cheap shortcuts that fail, with everything built on them, when a
  counterexample turns up.

The design is in [docs/design.md](docs/design.md). The state of the code, build commands and
what to do next are in [HANDOFF.md](HANDOFF.md); planned balance changes are in
[docs/balance-plan.md](docs/balance-plan.md).

## Playing

New players get **The Mathematician's Notebook**, which walks through the opening hour: power,
numerals, certified evens, Circuit Boards, the first definition and proof, induction (0 + n = n),
closure theorems (even + even = even), and the first trap (2n + 1 is always prime).

## Building

Needs JDK 25.

```
./gradlew build              # jar in build/libs, runs the unit tests
./gradlew runClient          # play in a development client
./gradlew runGameTestServer  # in-world game tests, headless
```

## What is inside

- `core/`: a small proof checker (LCF style), definitions, structures (monoids, equivalences,
  orders), certificates, conjectures and the world's save format, with no Minecraft code.
- Machines: Coal Dynamo and cables; Zero Source, Successor, Duplicator, Test Bench; Drafting
  Chamber, Equation / Property / Witness / Structure Benches, Instantiator, Rewriter, Assumption
  Chamber, Induction Engine, Conjunction and Modus Ponens Presses; Compiled Machine with theorem
  cards; Prime Forge; Conjecture Bench and blocks; Library, Graph Lens, Statement Conveyor and
  Containment Controller.

Art and sounds are original placeholders generated by `tools/gen_assets.py` and
`tools/gen_sounds.sh`.
